# HyperPulse v0.7 마케팅 재평가

## 판정: 제품의 약속은 더 구체적이지만, 재방문 개선은 아직 미검증

v0.7 이전에는 시장 분석, Telegram, Pulse가 각각 있었지만 사용자가
같은 사건의 변화·발송 이유·결과를 이어서 확인하기 어려웠다. 이제 세션
발행본을 다시 열 수 있고, 알림에서 확인된 체결과 포지션 변화를 구분하며,
성적표에서 놓친 신호와 관측 불가도 볼 수 있다. 이것은 코드와 테스트로
검증 가능한 개선이다. 채널 가입률·재방문·매매 성과의 개선은 입증되지 않았다.

| 사용자 행동 | 개선된 점 | 아직 약한 점 |
|---|---|---|
| 매일 장 열기 전에 웹 확인 | 지난 발행본과 비교 가능한 최대 2개 변화를 읽는다. | 첫 세션·표본 교체가 잦으면 비교가 비어 있다. 실제 30초 내 이해 여부는 미검증이다. |
| Telegram을 켜 두기 | 포지션 변경 이유, 검증 체결 여부, 판단 근거로 연결된다. | 검증 체결 비율과 지연 분포를 모른다. 로그인 때문에 근거 열람이 끊길 수 있다. |
| 결과를 확인하러 웹 복귀 | 15분 결과를 기간·자산별로 보고 누락도 숨기지 않는다. | 짧은 가격 방향 결과가 의사결정에 도움이 되는지, 비교 기준보다 나은지는 미검증이다. |

## 경쟁 재조사에서 남은 갭

- [Binance AI FAQ](https://www.binance.com/en/support/faq/detail/4a3b89b8024147938b0091d5e497800f):
  보유·관심 자산 중심 요약과 관심 목록 이상 움직임을 제공한다. HyperPulse의
  단일 채널에는 개인 관련성이 없다. 대형 AI 챗보다 자산 필터와 알림 미리보기가
  더 작은 다음 실험이다. [Binance Research](https://www.binance.com/en/research/analysis/binance-intelligence-a-first-look-at-next-gen-finance)의
  자사 앱 관측을 HyperPulse 유지율 목표로 그대로 사용하지 않는다.
- [Nansen Smart Alerts](https://release.nansen.ai/help/articles/6239622-ai-smart-alerts-101):
  이미 Hyperliquid 포지션 열기·닫기·변경 알림을 제공한다. 속도나 최초 기능을
  주장하기보다, 이벤트 근거와 사후 확인을 하나의 링크에서 보여주는 경험을 검증한다.
- [HyperTracker](https://docs.coinmarketman.com/hypertracker-dashboard):
  폭넓은 지갑·코호트와 세부 탐색이 강점이다. 전수 추적 대신 현재 표본 범위,
  비교 불가 이유, 스냅샷 시각을 메시지 가까이에 유지한다.

## 다음 개선 실험

1. **P0 — 가입 전 샘플 한 장.** 확인된/미확인 예시 각 하나를 준비하고,
   사용자가 30초 안에 ‘이번 변화’와 ‘누적 포지션’을 구분하는지 본다.
   실제 데이터 공개 승인 전에는 명확히 표시된 fixture를 사용한다.
2. **P0 — 알림 품질부터 검증.** 고정 기간에 성공·실패·미검증을 모두 포함해
   발송 지연, 중복, 원천 링크 정합성, 근거 열람 성공을 기록한다.
   지연이나 인증 이탈이 주요 문제라면 새로운 유형 추가보다 먼저 해결한다.
3. **P1 — 관심 자산 경로.** Beta 인터뷰에서 관심 자산을 받고, 먼저 웹
   브리프/성적표에 읽기 전용 필터를 시험한다. 개인 Telegram 라우팅은 수요 확인 후.
4. **P1 — 성적표의 비교 기준.** 관측 계약과 같은 시간대에서 단순 기준(예:
   직전 방향 유지)과 비교하는 방식을 먼저 정한다. 중첩 15분 신호는 독립
   관측으로 간주하지 않는다. 표본을 확보하기 전에는 ‘수익’, ‘승률’, ‘우위’를
   홍보하지 않는다.

추천 출시 문구: **“지난 세션 이후 달라진 고래 포지션을 확인하세요.
중요한 변화는 Telegram으로 받고, 확인된 체결과 판단 근거는 웹에서 보세요.”**
‘실시간’, ‘30초’, ‘정확도 우위’는 실제 검증 전 약속하지 않는다.

## Beta에서 확인할 증거

- 연속 발행본 브라우저 재방문 / 이전 발행본을 본 적격 브라우저-세션 쌍.
- Telegram 표시가 붙은 근거 열람 브라우저 수. 링크 공유나 브라우저 변경을
  구분할 수 없어 가입 전환율로 해석하지 않는다.
- 서로 다른 UTC 날짜에 성적표를 본 동의 브라우저 / 전체 성적표 동의 브라우저.
- 동일한 세션과 예시를 본 참가자가 ‘달라진 점’, ‘발송 이유’, ‘결과’를
  도움 없이 설명할 수 있는지 인터뷰로 확인한다.

측정은 기본 비활성이며 사용자 동의 표본은 전체 사용자를 대표하지 않는다.
실제 Preview, 고정 원천 샘플, 참가자 검증이 끝나기 전에는 공개 출시를 권하지 않는다.
